# Historical algorithm sources

Files here preserve the original analysis implementations selected from the evidence PACKs, with matching original hashes in provenance/SOURCE_MANIFEST.csv. They can contain historical absolute layouts and pre-later-session status values. They are not the portable release entry points and were not reexecuted unchanged in this production.

Use ../recompute_geometry.py, ../verify_independent.py and ../replay_auxiliary.py for tested coordinate and saved-output replay. Those scripts preserve input IDs and definitions without requiring the original private ZIP hierarchy. No command in the root README asks readers to run this archived directory.

The original primary common198 Tier0/1 subset is historically distinct from the later all-observed normalized-PDB screen. The canonical public interaction CSVs use the latter. Original code can list later auxiliary engines as NOT RUN at its own historical stage; verification/analysis_status.csv records the integrated status and scope.
